**Coordination:** If Plan 2 ships first and removes the password input from Login, Task 2 collapses to "username autoComplete only" and the password-related sub-steps are no-ops. Tasks 1, 3-7 are independent of Plan 2.

### Step 4.2: Implement bounds + keyboard

- [ ] **Step 4.2a: Define a constant**

```tsx
const MAX_QP_QUANTITY = 10;
```

- [ ] **Step 4.2b: Update the stepper markup (lines 636-651)**

Replace the entire `motion.div` block with:

```tsx
<motion.div
  initial={{ opacity: 0, height: 0 }}
  animate={{ opacity: 1, height: 'auto' }}
  className="pt-4 space-y-3"
>
  <label
    htmlFor="qp-quantity"
    className="text-[10px] font-black text-text-muted uppercase tracking-widest px-1"
  >
    Number of Papers Required
  </label>
  <div
    id="qp-quantity"
    role="spinbutton"
    aria-valuemin={1}
    aria-valuemax={MAX_QP_QUANTITY}
    aria-valuenow={qpQuantity}
    aria-label="Number of papers required"
    tabIndex={0}
    onKeyDown={(e) => {
      if (e.key === 'ArrowUp') {
        e.preventDefault();
        setQpQuantity((q) => Math.min(MAX_QP_QUANTITY, q + 1));
      } else if (e.key === 'ArrowDown') {
        e.preventDefault();
        setQpQuantity((q) => Math.max(1, q - 1));
      }
    }}
    className="flex items-center gap-4 bg-blue-50 p-2 rounded-2xl border border-blue-100 focus:outline-none focus:ring-2 focus:ring-curro-blue"
  >
    <button
      type="button"
      aria-label="Decrease number of papers"
      disabled={qpQuantity <= 1}
      onClick={() => setQpQuantity(Math.max(1, qpQuantity - 1))}
      className="w-12 h-12 bg-white rounded-xl flex items-center justify-center shadow-sm text-curro-blue font-black disabled:opacity-30"
```
